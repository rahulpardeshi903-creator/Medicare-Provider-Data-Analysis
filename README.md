**Medicare Provider Data Analysis**

Exploratory Data Analysis on Medicare Provider Dataset using Python

**Project Overview**

This project focuses on performing Exploratory Data Analysis (EDA) on a Medicare provider dataset to understand reimbursement patterns across different states and medical specialties. The objective was to clean the dataset, explore billing behavior, and extract meaningful insights related to Medicare payments.

The analysis involved working with real-world healthcare data to identify trends in submitted charges, total payments, service volume, and provider-level variations.

**Tools and Technologies**

-- Python

-- Pandas

-- Matplotlib

-- Seaborn

-- Jupyter Notebook

**Work Performed**

-- Cleaned the dataset by handling missing values and replacing inconsistent entries

-- Corrected incorrect data types to ensure accurate analysis

-- Performed grouping and aggregation to analyze specialty-wise and state-wise trends

-- Conducted correlation analysis between submitted charges and Medicare payments

-- Created visualizations to better understand reimbursement behavior

-- Structured the notebook into clear sections including data cleaning, analysis, and conclusions

**Key Insights**

-- A strong positive correlation exists between submitted charges and Medicare payments

-- Reimbursement amounts vary significantly across states

-- Certain specialties account for a larger volume of services and higher overall payments

-- Billing patterns directly influence total reimbursement trends

**Learning Outcome**

This project strengthened my practical understanding of data cleaning, transformation, aggregation, and visualization using Python. It also improved my ability to interpret real-world healthcare data and present insights in a structured and professional manner.

**Dataset**

The dataset used in this project is publicly available Medicare provider data.
