# Medicare Provider Data Analysis

## Project Overview

This project focuses on exploring and analyzing Medicare provider data to understand how healthcare reimbursements vary across different states and medical specialties. The goal was to clean the dataset, identify patterns in billing behavior, and extract meaningful insights related to Medicare payments.

Through this analysis, I worked with real-world healthcare data to examine trends in submitted charges, total reimbursements, service volume, and provider-level differences.

## Tools and Technologies

- Python  
- Pandas  
- Matplotlib  
- Seaborn  
- Jupyter Notebook  

## What I Did

- Cleaned the dataset by handling missing values and resolving inconsistencies  
- Corrected incorrect data types to ensure accurate analysis  
- Performed grouping and aggregation to analyze trends across states and specialties  
- Conducted correlation analysis between submitted charges and Medicare payments  
- Created visualizations to clearly represent reimbursement patterns  
- Structured the notebook into logical sections including data cleaning, analysis, and conclusions  

## Key Insights

- Submitted charges and Medicare payments show a strong positive relationship  
- Reimbursement amounts vary significantly from state to state  
- Certain medical specialties account for higher service volumes and overall payments  
- Billing behavior has a noticeable impact on total reimbursement trends  

## How to Run This Project

1. Clone the repository  
2. Install required libraries:  pip install pandas matplotlib seaborn
3. Open the notebook in Jupyter Notebook or JupyterLab  
4. Run the cells from top to bottom
